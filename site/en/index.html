For Linux · free and open source

An equalizer for all of Linux.

CJC Tune processes everything your PC plays (music, movies, games and calls) with a 10-band equalizer and effects. One extra audio output, and the result reaches your headphones exactly once, with no echo.

01

One more output. Nothing to set up per app.

CJC Tune adds an output called CJC Tune and makes it the default. Apps play into it without knowing; CJC Tune processes the sound and sends it to the real device.

  1. AppsBrowser, Spotify, games, calls
  2. CJC Tune outputVirtual device, system default
  3. Processor10-band EQ, effects, limiter
  4. Your headphonesOne copy only, no echo

Switch headphones in the system and it follows. If the audio server goes away it comes back by itself. Quit the app and sound returns to the normal output.

06

Frequently asked.

Does it work on Ubuntu, Linux Mint, Fedora and Arch?

It works on any distribution with PipeWire or PulseAudio. The AppImage runs everywhere; the .deb is for Debian, Ubuntu, Mint and derivatives. The code is tested against real PipeWire and PulseAudio on every change.

Is it free?

Yes. Open source, MIT license, no account, no ads.

Does it work with Spotify, browsers and games?

Yes. It processes the whole system output, so it applies to every app that plays sound, with nothing to set up per app.

The sound crackles or is gone. What do I do?

Right-click the tray icon and choose Restart audio service. It recreates the device and clears the filters in a moment. It is also on the Output page and available as a command: pkill -USR2 cjc-tune.

Does it send my data anywhere?

No. The only connection is asking GitHub whether a new version exists, and you can turn that off in Settings.

How is it related to FXSound?

CJC Tune grew out of FXSound for Linux, a community open-source project (MIT license), and has its own interface, code layout and features. It is not affiliated with FxSound for Windows.

How do I uninstall it?

AppImage: delete the file. .deb: sudo apt remove cjc-tune. Quitting the app always gives the sound back to the normal output.
