Equalizador para Ubuntu

Instale um equalizador que vale para tudo o que toca no Ubuntu, em dois minutos.

O Ubuntu não vem com um equalizador para o som do sistema. As configurações de som deixam escolher a saída e o volume, mas não mexem no grave, nos médios e nos agudos. Para isso é preciso um programa que fique entre os aplicativos e o seu fone.

O CJC Tune faz isso: ele cria uma saída de áudio chamada CJC Tune, coloca ela como padrão e processa tudo o que passa por ela com um equalizador de 10 bandas e efeitos. Funciona no Ubuntu 22.04, 24.04 e mais novos, com PipeWire (o padrão desde o 22.10) ou PulseAudio.

Instalar pelo .deb

  1. Baixe o arquivo cjc-tune_1.0.0_amd64.deb na página de instalação.
  2. Abra o terminal na pasta do download e rode sudo apt install ./cjc-tune_1.0.0_amd64.deb.
  3. Abra o CJC Tune pelo menu de aplicativos. O som do sistema passa a sair por ele na hora.

Ou usar o AppImage

O AppImage roda sem instalar. No Ubuntu 22.04 e mais novos ele precisa da biblioteca FUSE 2, que não vem instalada por padrão:

sudo apt install libfuse2t64   # Ubuntu 24.04 ou mais novo
sudo apt install libfuse2      # Ubuntu 22.04
chmod +x cjc-tune_1.0.0_amd64.AppImage
./cjc-tune_1.0.0_amd64.AppImage

Ajustar o som

  • Escolha uma predefinição (Música, Filmes, Jogos, Grave reforçado) ou arraste os pontos da curva.
  • Em Efeitos, o HyperBass encorpa o grave e a Fidelidade devolve brilho aos agudos.
  • Gostou? Use Salvar… para guardar a sua curva com um nome.

Se o som travar ou estalar

Clique com o botão direito no ícone do CJC Tune na bandeja e escolha Reiniciar serviço de áudio. Ele recria a saída e zera os filtros sem fechar nada. Fechar o app devolve o som para a saída normal do Ubuntu.
